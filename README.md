# SteelArt Preview

Bu depo yalnızca SteelArt mağazasının tarayıcıdan incelenebilen görsel ön izlemesini barındırır.

- Ana proje ve gerçek PHP/MySQL uygulaması özel `Finsate-Site` deposunda kalır.
- Bu ön izleme gerçek sipariş, ödeme, oturum veya veritabanı bağlantısı içermez.
- Sayfa, kaynak projedeki mevcut `preview/index.html` dosyasından aktarılmıştır.
